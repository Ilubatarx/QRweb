# Descargas de QRforma

- [Descargar la web lista para subir a ihost](https://github.com/Ilubatarx/QRweb/raw/refs/heads/descargas-qrforma/descargas/qrforma-ihost.zip)
- [Descargar código fuente editable](https://github.com/Ilubatarx/QRweb/raw/refs/heads/descargas-qrforma/descargas/qrforma-codigo.zip)
- [Guía de instalación en cPanel](INSTALAR-IHOST.txt)

Sube **qrforma-ihost.zip** a la carpeta de tu subdominio desde el Administrador de archivos de cPanel y extráelo allí. index.html y assets/ deben quedar directamente dentro de esa carpeta. La guía completa también está dentro del ZIP.

El paquete está compilado y probado en la raíz y en una subcarpeta. Genera 3MF con dos colores, STL, PNG y SVG. Estos enlaces entregan archivos; la web se publica cuando se suben al hosting.
